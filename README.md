# 🧟 Earn to Die — Clone (HTML5 + Matter.js)

Полноценный браузерный клон **Earn to Die**: физика колёс и подвески, зомби,
процедурная пустошь, деньги, магазин, апгрейды, машины, уровни и сохранения.

---

## 🚀 Как запустить

### Способ 1 — просто открыть файл
Скачай папку и открой `index.html` двойным кликом.
> ⚠️ Из-за ES-модулей (`<script type="module">`) браузер заблокирует `import`
> при открытии через `file://`. Используй способ 2.

### Способ 2 — локальный сервер (рекомендуется)

**Python:**
```bash
cd earn-to-die
python -m http.server 8000
# открыть http://localhost:8000
